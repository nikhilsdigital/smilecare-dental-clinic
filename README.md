# SmileCare Dental Clinic

Professional Dental Clinic website built with:

- Next.js
- TypeScript
- Tailwind CSS v4
- Lucide React
- App Router

## 1. Install dependencies

```bash
npm install
```

## 2. Start development server

```bash
npm run dev
```

Open:

http://localhost:3000

## 3. Build for production

```bash
npm run build
```
